# Hosyond documentation

The final wiring and firmware instructions are now maintained in:

- [README](README.md): hardware, wiring, build/upload and validation summary.
- [User manual](USER_MANUAL.md): touch controls, Settings, battery reads and USB bridge.
- [Release notes](RELEASE_NOTES.md): Hosyond release 1.0.0 changes and test limits.

Final mapping: **GPIO23 DATA / GPIO27 ENABLE**. On the owner's adapter these are
battery pin 6 DATA / pin 2 ENABLE; identify contacts by function on other adapters.
Use the normal **hosyond-cyd28** environment.
